# 9장 · configuration: 화살표 전체 배치 하나

| **장의 핵심 질문**   | 구 위의 화살표 하나가 아니라 “모든 화살표의 전체 배치”를 하나의 상태로 보려면?                                                                        |
|----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| **선행 개념**        | field와 S²→S² map.                                                                                                                                    |
| **학습 목표**        | configuration을 장 전체의 한 배치로 정의하고, domain 한 점/target 한 점/configuration 한 개를 구분한다.                                               |
| **사용할 source**    | G02 §4–6; G03 §4–5.                                                                                                                                   |
| **필요한 그림 ID**   | F013                                                                                                                                                  |
| **필요한 추가 그림** | 없음.                                                                                                                                                 |
| **반드시 넣을 비유** | 체스판의 말 하나가 아니라 판 전체의 배치 하나가 “게임 상태”인 것.                                                                                     |
| **비유의 한계**      | 연속장은 유한한 체스말보다 훨씬 많은 자유도를 가지며 보통 무한차원 기술이 필요하다.                                                                   |
| **최소 수학**        | 한 configuration을 n(·) 또는 n으로 쓰고, n(x)는 그 configuration의 한 점에서의 값으로 구분.                                                           |
| **오해 방지 상자**   | configuration-space의 “한 점”을 domain S²의 한 점과 혼동하지 않기.                                                                                    |
| **현재 증명상태**    | configuration은 모델의 상태를 기술하는 수학 언어. 어떤 configuration이 실제 물리상태인지의 ontology는 이후 Gate 문제와 연결되며 현재 전체적으로 OPEN. |
| **확인문제 방향**    | 주어진 표현이 domain point, field value, full configuration 중 무엇인지 분류.                                                                         |
