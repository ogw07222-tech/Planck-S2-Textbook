# 8장 · Q=1이 뜻하는 것과 뜻하지 않는 것

| **장의 핵심 질문**   | “Q=1”의 숫자 1을 왜 1 bit, 전하 −e, 전자 한 개와 동일시하면 안 될까?                                          |
|----------------------|---------------------------------------------------------------------------------------------------------------|
| **선행 개념**        | degree Q의 정의와 정수 분류.                                                                                  |
| **학습 목표**        | 위상적 degree와 정보량·전기전하·입자 정체성을 서로 다른 물리/수학 객체로 분리한다.                            |
| **사용할 source**    | G05 §2, §12, §14; A01 §2.4, §3(G05/G06 감사), §5.1.                                                           |
| **필요한 그림 ID**   | F010 재사용                                                                                                   |
| **필요한 추가 그림** | F1X05: “Q=1이 말하는 것 / 말하지 않는 것” 양쪽 분기 도식.                                                     |
| **반드시 넣을 비유** | 도서관 분류번호의 ‘1’은 책의 페이지 수나 가격이 아닌 것과 비슷한 ‘종류 라벨’ 비유.                            |
| **비유의 한계**      | degree는 단순 임의 라벨이 아니라 연속변형에 보존되는 수학적 불변량이다. 비유가 그 구조까지 설명하지는 못한다. |
| **최소 수학**        | Q=1; log₂d와 Q는 서로 다른 기호/정의임을 나란히 표시. 전기전하 q_e=−e와도 별개.                               |
| **오해 방지 상자**   | Q=1≠1 bit; Q=1≠charge −e; Q=1≠electron identity.                                                              |
| **현재 증명상태**    | “Q=1=1 bit”식 등치는 FALSIFIED AS WRITTEN/금지. charge −e 및 electron identity 연결: OPEN.                    |
| **확인문제 방향**    | 잘못된 등치 문장을 골라 각 양이 무엇을 세는지 다시 쓰기.                                                      |
